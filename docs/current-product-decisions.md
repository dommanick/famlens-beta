# 当前产品决策索引

更新时间：2026-06-21

## 产品定位

FamLens 是面向海外移民家庭的 AI 购物助手，不是通用翻译器，也不是医疗健康管理产品。

## 第一阶段目标

先做用户量、留存、分享和数据积累，不急于强推订阅。

## 核心功能优先级

1. 拍商品看懂：外文标签、成分、说明、用法、注意事项。
2. 扫小票记录：形成家庭购物记忆和后续报告基础。
3. 语音问 AI：适合老人和海外购物现场。
4. 问店员卡：生成可给店员看的当地语言大字卡。
5. 分享图文卡：商品判断卡、小票摘要卡、避坑卡。
6. 家庭共享：家庭码、成员加入、共同积累记录。

## 商业化原则

- ToC 订阅保留，但早期不强卡基础功能。
- ToB 广告、优惠券、返现、品牌合作更有长期想象空间。
- Offer / Cashback / Sponsored 模块先预留，默认关闭。
- 安全判断和健康提醒不能被商业内容影响。

## 结果页新方向

商品扫码后页面：

- 独立判断。
- 商品解释。
- 用法。
- 家庭适配。
- 注意事项。
- 分享卡。
- 未来可选优惠/同类商品入口。

小票扫码后页面：

- 总额、日期、商店、商品数。
- 商品清单。
- 分类结构。
- 家庭购物记忆。
- 饮食/消费信号。
- 未来返现/offer 入口。

## 增长重点

分享是核心增长功能，不是附属功能。

增长飞轮：

拍商品 -> 得到有用结果 -> 分享给朋友/家人/社群 -> 新用户使用 -> 小票和商品数据沉淀 -> 家庭购物记忆增强 -> ToB 商业化增强。
