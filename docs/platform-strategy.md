# Platform Strategy

第一版产品要验证的是“家庭主要采购者拍一下，马上看懂并行动”，不是验证公众号聊天机器人。

## Product Channel

推荐路径：

1. 当前内测版用 H5 / PWA 页面验证核心体验，并使用国际化品牌 FamLens。
2. 下一版按独立 App 产品设计，优先保障相机、语音、历史记录、家庭报告和订阅能力。
3. 微信小程序、LINE MINI App、Telegram Mini App 或 WhatsApp 链接只作为各地区入口，不作为唯一产品载体。
4. 公众号只保留为入口、通知或客服承接，不作为主要分析界面。

## Known Platform Limits

| 场景 | 风险 | 第一版处理 | 正式版处理 |
| --- | --- | --- | --- |
| 公众号被动回复 | 图片分析超过微信回复窗口，体验会断 | 不再把公众号作为主流程 | 公众号只发入口链接或客服提示 |
| 公众号链接和图片权限 | 图文卡需要点链接，可能打不开或需要额外权限 | H5 页面内直接展示卡片 | 小程序内生成图片卡并可保存 |
| H5 拍照 | 内置浏览器对相机、文件权限不完全可控 | 使用 `<input capture>` 做原型验证 | 独立 App 使用原生相机能力 |
| AI 图片输入 | 大图、弱网或接口限制会导致慢或失败 | 限制 8MB，直接上传后分析 | 前端压缩，后端对象存储，失败重试 |
| 语音播放 | 浏览器语音能力不稳定，内置浏览器差异大 | 使用浏览器 `speechSynthesis` 验证 | 服务端 TTS 生成音频，App 内播放 |
| SVG 图文卡 | 部分环境对 SVG 支持有限 | H5 内嵌 SVG 先验证排版 | 正式版输出 PNG 或 Canvas 海报 |
| 订阅付费 | 不同平台抽成、规则、可用国家不同 | 暂不绑定平台支付 | 后端统一权益，App Store/Google Play/Stripe 适配 |
| 隐私 | 商品照片、家庭提醒可能包含个人信息 | 本地文件和日志不进 Git | 明确保存期限，敏感信息脱敏 |

## MVP Rule

每次拍照后，页面必须一次性给出：

- 这是什么
- 建不建议买
- 怎么用
- 有什么好处
- 需要注意什么
- 可以直接给店员看的英文
- 可以播放给老人听的语音摘要

用户不应该被要求连续问五六个问题，产品要把高频判断提前做掉。
